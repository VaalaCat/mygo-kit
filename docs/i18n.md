# Localization

The library’s own text, such as “Copy code”, “Cancel”, and “No results”, follows MyGo’s `Context.Locale()`: the current window’s display language. English and Simplified Chinese are built in. Your application still translates its own UI text.

The library does not register application languages or change the global language.

## Enable Chinese

```go
import (
	"github.com/egoist/mygo"
	_ "github.com/egoist/mygo/locales/zh-Hans"
)

func main() {
	mygo.App.SetLanguages("en", "zh-Hans")
	// ...
}
```

- `mygo.App.SetLanguages("en", "zh-Hans")` declares the languages your application supports. Without it, MyGo displays English even for Chinese users.
- Import `github.com/egoist/mygo/locales/zh-Hans` to translate MyGo’s own text, such as “Cut” and “Paste” in an input’s context menu. The library’s Chinese text is already built in and needs no extra import.

## Switch languages

```go
mygo.App.SetLocale("zh-Hans") // Takes effect immediately and persists across restarts
mygo.App.SetLocale("")        // Follow the system language again
```

All windows redraw immediately after switching. The “EN / Chinese” button in the gallery header uses this approach.

## Override or extend translations

The library’s catalog namespace is `mygokit`. To change a translation or add a language the library does not provide, add `mygokit.<key>` entries to your application’s MyGo catalog:

```json
{
  "mygokit.cancel": "Abbrechen",
  "mygokit.confirm": "OK"
}
```

Lookup starts with the application’s current language, falls back to its source language, and finally uses the library’s English text. Add `mygokit.*` entries for a language to use your translations in that language.

Keys you can override:

- Copying: `copy` (“Copy” in the context menu), `copied` (“Copied”, shown briefly after copying), `copyJSON`, `copyOutput`, `copyMarkdown`, and `copyCode`.
- General: `cancel`, `confirm`, `close`, `search`, `noResults`, and `loading`.
- Command palette: `commandSearch`.
- Images: `loadingImage`, `imageUnavailable`, `retryImage`, `fit`, and `originalSize`.
- Content: `output`, `task`, and `terminal`.
- Workspace and scrolling: `toggleSidebar`, `jumpToLatest`, and `removeAttachment`.
- Status: `statusRunning`, `statusFailed`, `statusInterrupted`, `statusBlocked`, and `statusStopped`.

## Override labels in Opt

To change a label for one component instance, set it in the component’s Opt without changing the catalog:

- [JSONTree](/components/json-tree): `JSONOpt.Title`, `JSONOpt.CopyLabel`.
- [ANSIOutput](/components/ansi-output): `ANSIOutputOpt.Title`, `ANSIOutputOpt.CopyLabel`.
- [PatchLines](/components/patch): `PatchOpt.Title`, `PatchOpt.CopyLabel`.
- [Markdown](/components/markdown): `MarkdownOpt.CopyLabel` (copy the full source), `MarkdownOpt.CodeCopyLabel` (copy a code block).
- [DialogWith](/components/dialog): `DialogOpt.ConfirmLabel`.
- [Select](/components/select): `SelectOpt.SearchPlaceholder`.
- [CompletionMenu](/components/completion-menu): `CompletionOpt.Empty`.
- [Tab](/components/tabs): `TabOpt.CloseLabel` (the close button’s accessible name; no default, so provide it yourself).

Labels set in Opt take priority over the catalog. When unset, `JSONOpt.Title` and `PatchOpt.Title` use the fixed English labels `JSON` and `Patch`. They do not change with the language.

## Your own text

The library handles only its own text. Choose the button labels, titles, and descriptions you pass to components based on `c.Locale()`:

```go
label := "保存"
if c.Locale() != "zh-Hans" {
	label = "Save"
}
kit.PrimaryButton(c, label)
```

For production applications, use MyGo’s catalog. See MyGo’s [i18n documentation](https://github.com/egoist/mygo/blob/main/docs/i18n.md).
