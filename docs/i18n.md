# 多语言

本库自己的文案（例如“复制代码”“取消”“没有匹配项”）跟随 MyGo 的 `Context.Locale()`，也就是当前窗口显示的语言。内置英文和简体中文。你自己界面上的文字，仍然由你的应用负责翻译。

本库不注册应用的语言，也不改全局语言。

## 打开中文

```go
import (
	"github.com/egoist/mygo"
	_ "github.com/egoist/mygo/locales/zh-Hans"
)

func main() {
	mygo.App.SetLanguages("en", "zh-Hans")
	// ...
}
```

- `mygo.App.SetLanguages("en", "zh-Hans")` 声明应用支持的语言。没有这一步，MyGo 对中文用户也显示英文。
- 导入 `github.com/egoist/mygo/locales/zh-Hans`，才会翻译 MyGo 自己的文案，例如输入框右键菜单里的“剪切”“粘贴”。本库的中文文案已经内置，不需要额外导入。

## 切换语言

```go
mygo.App.SetLocale("zh-Hans") // 马上生效，并记住到下次启动
mygo.App.SetLocale("")        // 恢复跟随系统语言
```

切换后所有窗口立刻重画。画廊顶栏的“EN / 中文”按钮就是这样做的。

## 覆盖或补充文案

本库的文案目录 namespace 是 `mygokit`。应用想改某一条，或者给本库没有的语言补翻译，在自己的 MyGo catalog 里写 `mygokit.<key>`：

```json
{
  "mygokit.cancel": "Abbrechen",
  "mygokit.confirm": "OK"
}
```

解析顺序是应用当前语言，再退到应用的源语言，最后是本库的英文。所以只要补了某个语言的 `mygokit.*`，在这个语言下就会用你写的。

可以覆盖的 key：

- 复制：`copy`（右键菜单的“复制”）、`copied`（复制后短暂显示的“已复制”）、`copyJSON`、`copyOutput`、`copyMarkdown`、`copyCode`。
- 通用：`cancel`、`confirm`、`close`、`search`、`noResults`、`loading`。
- 命令面板：`commandSearch`。
- 图片：`loadingImage`、`imageUnavailable`、`retryImage`、`fit`、`originalSize`。
- 内容：`output`、`task`、`terminal`。
- 工作区和滚动：`toggleSidebar`、`jumpToLatest`、`removeAttachment`。
- 状态：`statusRunning`、`statusFailed`、`statusInterrupted`、`statusBlocked`、`statusStopped`。

## 在 Opt 里覆盖名称

只想改某一个组件实例的名称，不用动 catalog，直接在它的 Opt 里设：

- [JSONTree](/components/json-tree)：`JSONOpt.Title`、`JSONOpt.CopyLabel`。
- [ANSIOutput](/components/ansi-output)：`ANSIOutputOpt.Title`、`ANSIOutputOpt.CopyLabel`。
- [PatchLines](/components/patch)：`PatchOpt.Title`、`PatchOpt.CopyLabel`。
- [Markdown](/components/markdown)：`MarkdownOpt.CopyLabel`（复制整份源文）、`MarkdownOpt.CodeCopyLabel`（复制代码块）。
- [DialogWith](/components/dialog)：`DialogOpt.ConfirmLabel`。
- [Select](/components/select)：`SelectOpt.SearchPlaceholder`。
- [CompletionMenu](/components/completion-menu)：`CompletionOpt.Empty`。
- [Tab](/components/tabs)：`TabOpt.CloseLabel`（关闭按钮的可访问名称，没有默认值，请自己传）。

Opt 里设的名称优先于 catalog。注意 `JSONOpt.Title` 和 `PatchOpt.Title` 没设时是固定的英文 `JSON` 和 `Patch`，不随语言变化。

## 你自己的文字

本库只管自己的文案。按钮文字、标题、说明这些你传进组件的字符串，要自己按 `c.Locale()` 选好再传：

```go
label := "保存"
if c.Locale() != "zh-Hans" {
	label = "Save"
}
kit.PrimaryButton(c, label)
```

正式的应用建议用 MyGo 的 catalog，见 MyGo 的 [i18n 文档](https://github.com/egoist/mygo/blob/main/docs/i18n.md)。
